# ELSDTU

边缘计算网关管理中台项目。目标是统一管理网关及其下挂设备，并提供云组态和零代码流程编排能力。

## 当前状态

已完成工作计划第 1 步和第 2 步。第 3 步改用 Node.js，提供可运行的网关注册、心跳与在线状态验证服务；远程服务器部署待连接信息确认。此阶段尚未接入真实网关。

## 快速验证

需要 Node.js 22 或更新版本，不依赖第三方 npm 包：

```powershell
node --test
```

服务启动及模拟网关步骤见[Node 验证环境](docs/03-Node验证环境.md)。
